# kangminlog.github.io

GitHub Pages 블로그. 빌드 도구를 로컬에 깔지 않는다 — 깃허브가 Jekyll 로 만든다.

## 글 추가

`_posts/YYYY-MM-DD-영문-제목.md` 를 만들고 맨 위에 넣는다.

```
---
layout: post
title: "제목"
date: 2026-09-30 09:00:00 +0900
---
```

나머지는 마크다운이다. `git push` 하면 1~2분 뒤 반영된다.

**함정 하나.** `date` 를 현재 시각보다 **뒤로** 적으면 Jekyll 이 그 글을 감춘다.
빌드는 성공하는데 목록에 안 뜨고 URL 은 404 라 원인을 찾기 어렵다.
글을 미리 써두더라도 발행할 때 날짜를 현재 이전으로 고친다.

## 로컬에서 미리 보기 (선택)

```
bundle exec jekyll serve
```

Ruby 와 Jekyll 이 필요하다. 없어도 push 해서 확인하면 된다.

## 글 목록

**OpenTelemetry**
- 자바 에이전트는 어떻게 코드를 안 고치고 추적하나
- OTLP 는 벤더 종속을 어떻게 끊는가 — 그리고 어디까지만 끊는가
- 트레이스·로그·메트릭을 하나로 묶는 것은 무엇인가
- OpenTelemetry Collector 의 수신-가공-송신 파이프라인

**ClickHouse**
- APM 백엔드에서 집계를 적재 시점으로 옮기기 — 롤업
- MergeTree 정렬 키와 파티션을 고르는 기준

**인프라·운영**
- ARM 서버에 관측 스택을 통째로 올리기
- 인터넷이 없는 현장에 서버를 넣는다는 것
- 보존 기간을 어떻게 산출하나 — 추측하지 않고 재는 법
- 정전이 나면 어디까지 살아남나 — 전원을 실제로 끊어본 기록
- 관측 파이프라인의 병목은 대체로 생각한 곳에 없다
- SNMP 로 장비를 볼 때 — 표준 MIB 와 벤더 MIB
